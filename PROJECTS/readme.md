# 🚀 Projects

This directory serves as an index of the AI, Backend and System Design projects I've built while exploring LLMs, Agentic AI, RAG, Observability and Distributed Systems.

Each project is maintained in its own GitHub repository (or within this learning repository) with complete source code, documentation, architecture diagrams and setup instructions.

---

## 🤖 AI Conversational Chatbot — Observability Platform

A production-oriented AI Career Mentor chatbot demonstrating LLM observability using LangSmith. The project focuses on tracing, prompt debugging, latency analysis, token usage, and production monitoring of AI applications.

🔗 Repository: https://github.com/aks281415/langsmitch-monitoring-tracing

---

## 🤝 Multi-Agent Blog Generator (A2A Protocol)

A distributed multi-agent application implementing Google's Agent-to-Agent (A2A) Protocol. Independent Research, Summarizer, and Writer agents communicate through standardized JSON-RPC messages coordinated by an Orchestrator.

🔗 Repository: https://github.com/aks281415/a2a-blog-writer

## ☕ AI-Powered Coffee Service Chatbot

A full-stack multi-agent conversational AI system integrating Gemini, Retrieval-Augmented Generation (RAG), and an Apriori-based recommendation engine to deliver contextual responses while reducing hallucinations.

🔗 Repository: https://github.com/aks281415/BEAN-STREET-COFFEE-SHOP

## 🔗 URL Shortener & Analytics Platform

A production-ready full-stack URL shortening service with click analytics, Dockerized backend services, PostgreSQL, AWS deployment, and REST APIs.

🔗 Repository: https://github.com/aks281415/url-shortener

## 📄 Vectorless RAG

A reasoning-driven Retrieval-Augmented Generation (RAG) system powered by PageIndex, eliminating the need for vector embeddings while enabling accurate document retrieval and question answering.

🔗 Repository: https://github.com/aks281415/vectorless-rag
